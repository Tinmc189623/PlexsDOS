# Shell 命令

| 命令 | 功能 |
|------|------|
| `help` | 显示帮助信息 |
| `cls` | 清屏 |
| `ver` | 显示版本信息 |
| `echo <text>` | 输出文本 |
| `ls` | 列出磁盘文件 |
| `type <file>` | 显示文件内容 |
| `run <file>` | 加载并执行 .comx 程序 |
| `reboot` | 重启系统 |
| `mem` | 显示内存信息 |
| `users` | 用户管理 |
| `edit <file>` | 文本编辑器 |
| `CDIR` | 列出光盘根目录 |
| `CCAT <file>` | 显示光盘文件内容 |
| `CDMOUNT` | 挂载光盘 |
