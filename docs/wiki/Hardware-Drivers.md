# 硬件驱动

## 存储

- **ATA PIO/DMA**: 通过 PCI 枚举的 IDE 控制器
- **AHCI SATA**: 高级主控接口, NCQ 支持
- **FDC**: 软盘控制器, 马达状态机
- **ATAPI CD-ROM**: 通过 ATA 包命令访问

## 输入

- **PS/2 键盘**: 扫描码驱动, 环形缓冲区, Shift/Caps
- **PS/2 鼠标**: GUI 集成, 相对位移

## 显示

- **VGA 文本模式**: 80x25, 0xB8000 显存
- **VGA 图形模式**: 帧缓冲操作

## 其他

- **COM1 串口**: 调试输出 (115200 baud)
- **PCI 总线**: 设备枚举, BAR 配置
