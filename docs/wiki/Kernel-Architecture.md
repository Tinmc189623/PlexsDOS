# 内核架构

PlexsDOS 内核采用模块化分层架构，运行在 x86 32-bit 保护模式。

## 架构层

```
┌─────────────────────────────────────────────┐
│                  Shell / GUI                 │
├─────────────────────────────────────────────┤
│               System Calls (INT 21h)         │
├─────────────────────────────────────────────┤
│   FS Layer  │  Scheduler  │  Driver Model   │
│  (FAT12/32) │  (Preempt)  │  (ATA/AHCI/...) │
├─────────────────────────────────────────────┤
│         Memory Management (Paging + PFA)    │
├─────────────────────────────────────────────┤
│     GDT │ IDT │ PIC │ CPU Detection         │
├─────────────────────────────────────────────┤
│              Bootloader (BIOS)               │
└─────────────────────────────────────────────┘
```

## 核心模块

- **引导系统**: 软盘/硬盘 MBR+VBR/ISO El Torito/VMDK
- **保护模式**: x86 32-bit, GDT (Ring 0-3 + TSS)
- **中断管理**: IDT + 8259A PIC, C++ OOP InterruptManager
- **内存管理**: 4KB 分页, 物理帧分配器
- **进程调度**: 抢占式多任务, 时间片轮转
